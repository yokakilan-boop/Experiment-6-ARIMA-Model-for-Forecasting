# Experiment 6: ARIMA Model for Forecasting

## Aim

To evaluate predictive models using performance metrics.

## Algorithm

1.  **START**
2.  Prepare stationary time series.
3.  Identify ARIMA -- (p, d, q) parameters using ACF/PACF.
4.  Fit the ARIMA model on the data.
5.  Forecast future periods and plot the results.
6.  Evaluate forecast accuracy.
7.  **STOP**

## Program
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.tsa.arima.model import ARIMA
from sklearn.metrics import mean_squared_error, mean_absolute_error

# Prepare time series data
data = [120, 125, 130, 128, 135, 140, 138, 145,
        150, 148, 155, 160, 158, 165, 170, 168]

series = pd.Series(data)

# Split data into training and testing
train = series[:-4]
test = series[-4:]

# Fit ARIMA model
model = ARIMA(train, order=(1, 1, 1))
model_fit = model.fit()

# Forecast future values
forecast = model_fit.forecast(steps=4)

# Display forecast
print("Actual Values:", list(test))
print("Predicted Values:", list(np.round(forecast, 2)))

# Evaluate accuracy
mse = mean_squared_error(test, forecast)
mae = mean_absolute_error(test, forecast)
rmse = np.sqrt(mse)

print("MAE:", round(mae, 2))
print("MSE:", round(mse, 2))
print("RMSE:", round(rmse, 2))

# Plot results
plt.plot(series, label="Actual Data")
plt.plot(range(12, 16), forecast, label="Forecast")
plt.title("ARIMA Time Series Forecasting")
plt.xlabel("Time")
plt.ylabel("Values")
plt.legend()
plt.show()

## Output
